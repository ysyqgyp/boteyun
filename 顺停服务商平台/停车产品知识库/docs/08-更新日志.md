# 8. 更新日志

云端更新日志 2022年10月25日星期二

- 半云端 V3.1.1 升级内容在云端皆已更新
- 云坐席 V2.0 版本正式发布（坐席注：可以挂机，没有说话自动挂机按 5 分钟不挂断也自动挂断）
- 微信支付服务商改为恒信通，微信支付服务商小时费率 0.6%/时间 点开始正常
- 每个入口只能添加一个进场或出场车牌，一个车牌同时只能进一次
- 本地云端切换：支持切换调整
- 无人值守支持两个版本：免费版（绑定微信推送 + 扫码电话呼叫），云坐席收费版（扫码呼叫到管理员，语音视频对讲）
- 优化环境监控功能
- 相机上云失败问题排查方法
- 访客预约操作说明
- 一位多位及一位多车模式启动
- 支持接口调整
- 业务系统上新
- 支持“呼叫转移”功能
- 服务人员权限设置，部分功能开启后受限
