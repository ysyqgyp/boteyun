# 3. 安装操作教程

## 3.1 半云端安装调试

视频地址：https://www.bilibili.com/video/BV13g411a7jT/（BV 号：BV13g411a7jT；视频为 Bilibili 内嵌播放器；视频文件不入库）

无人值守可不安装岗亭收费系统，若需安装岗亭收费系统请下载，切记：请勿安装在C盘

调试常见问题：

安装后显示，请检查以下几种情况：

1. 系统是否为64位操作系统，系统目前只支持64位
2. 若安装包在C盘，请执行或卸载服务后复制到其他盘，C盘存在权限问题

若注册成功后相机识别无反应，可尝试重新下发车场参数，点击一次即可，如下图：

相机识别正常进出平台也有记录，请检查相机对应的波特率是否与控制卡相对应

若登录提示未查询到停车场信息，可能是数据未同步到本地，可尝试重新下发车场参数

## 3.2 纯云端安装调试

视频地址：https://www.bilibili.com/video/BV1SP4y1s7Uo/（BV 号：BV1SP4y1s7Uo；视频为 Bilibili 内嵌播放器；视频文件不入库）

打开，按以下视频操作即可

无人值守可不安装岗亭收费系统，若需安装岗亭收费系统请下载，切记：请勿安装在C盘

调试常见问题：

一键上云后平台查看设备没有上线请检查以下几种情况：

1. 相机是否连通外网，如果确认有网检查相机的网关是否正确，正常是8.8.8.8，114.114.114.114
2. 老版本上云工具臻识RM选择，臻识R3选择

2.2.1.2022032803版本的上云工具RM和R3都选择ZS纯云

语音屏显没有反应请检查一下几种情况：

3. 检查控制卡是否选择了对应的型号
4. 检查相机波特率是否正确，正常情况下系统会按照控制卡默认波特率下发
5. 检查485通讯接线是否正确
6. 任何情况下升级一次连上后不能再重复升级，重复升级会导致不能连上平台，切记切记！
