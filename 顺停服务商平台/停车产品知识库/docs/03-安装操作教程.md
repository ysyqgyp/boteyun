# 3. 安装操作教程

## 3.1 半云端安装调试

视频地址：https://www.bilibili.com/video/BV13g411a7jT/（BV 号：BV13g411a7jT；视频为 Bilibili 内嵌播放器；视频文件不入库）

调试常见问题：

安装后显示，在“系统配置”中点击“系统设置”。

系统设置页面。

若安装包提示缺少某程序，请检查安装包是否包含该程序。

若注册成功后相机识别无反应，可尝试重新下发车场参数，点击一次即可，如下图：（图为资源管理器截图，路径为“电脑 > 本地磁盘（D:）> 相机灯和… > g > 城市停车场管理系统LiteV2.9.7”，列为名称、修改日期、类型、大小）
