# 9. 半云端 FAQ

半云端岗亭端常见问题：

Q1：Ping 相机 IP 连通，但是日志一直显示连不上？

A1：IP 被别的机器使用，重新设置相机 IP。

Q2：提示端口冲突，软件无法安装，如何解决？

A2：80 端口被占用，停用 World Wide Web Publishing Service、SQLServer 前缀的服务、Apache Tomcat 前缀的服务。

（本章仅上述两个问答。）
