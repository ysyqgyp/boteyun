# 2. 安装包

## 2.1 传统本地系统、半云系统和纯云系统的区别

本节除标题外无其他引言文字，只有一张对比表：

| | 💻 传统本地系统 | 📺 半云系统 | 🌏 纯云系统 |
| --- | --- | --- | --- |
| 服务器 | *必须 | *必须 | 无需服务器 |
| 岗亭电脑 | *必须打开岗亭软件才可正常运行 | 选用，也可不打开岗亭软件实现无人值守 | 选用，也可不打开岗亭软件实现无人值守 |
| 网络 | 内网（外网断网可运行） | 内网+外网（外网断网可运行） | 外网（外网断网月租车进出，临时车小程序拍照识别进出） |
| 数据同步 | 经常存在数据不同步 | 完全同步 | 完全同步 |
| 数据安全性 | 电脑坏了数据丢失不可恢复 | 云端拥有完整数据，可随时同步 | 云端数据多重防备，确保数据不丢失 |
| 移动端功能 | 只能做远程开关闸简单操作 | 可在移动端管理整个车场，所有功能皆可在小程序端操作 | 可在移动端管理整个车场，所有功能皆可在小程序端操作 |
| 断电 | 不可用 | 小程序扫车牌进出，费用不丢失 | 小程序扫车牌进出，费用不丢失 |
| 系统升级 | 向日葵或者现场升级 | 移动端或电脑网页端随时点击升级 | 升级无感知 |
| Linux 盒子 | 不支持 | 支持 | 无需盒子 |
| 布线 | *必须 | *必须 | 免布线 |
| 操作管理 | 向日葵远程操作或现场本地操作 | 可在云端、小程序实时操作、管理整个车场 | 可在云端、小程序实时操作、管理整个车场 |
