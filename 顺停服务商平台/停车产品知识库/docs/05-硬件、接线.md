# 5. 硬件、接线

## 5.1 如何确认相机类型

请按以下步骤在记录中查看相机的标注信息：

请在读卡器里查看：若显示“臻识 R3”，则为 R3 相机；若显示“臻识 RM”，则为 RM 相机。

注意：在控制卡上标注相机类型请查看相机外壳上的标签或外包装。
