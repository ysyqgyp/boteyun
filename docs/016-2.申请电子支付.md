#### **车场申请电子支付可通过以下三种方式：**  
方式1.**<font style="color:rgb(255,0,0);">扫码申请支付</font>**
首先，登录服务商平台，找到需要开通支付的车场项目。

+ 操作路径：登录【服务商平台】 -> 点击【项目管理】 -> 在项目列表中找到目标车场（如“XXX停车场”） -> 点击操作栏中的 【申请支付】 按钮。  
**<font style="color:rgb(255,0,0);">注意：二维码并非通用，一个车场对应一个二维码</font>**  


![](https://cdn.nlark.com/yuque/0/2026/png/49636354/1785831627796-38b03056-a16e-4e33-a657-f2232a0682e7.png)  


#### 方式2.<font style="color:#DF2A3F;">小程序申请支付</font>
+ 操作路径：登录【壹家云助手】 -> 点击【车场名称】进入车场 -> 在【管理中心】下拉找到【申请支付】 -> 点击 【申请支付】 按钮选择对公或者对私进行资料填写提交。  
  
![](https://cdn.nlark.com/yuque/0/2026/png/49636354/1785831649869-4acd7240-d262-494a-8a77-fb8be8385aea.png)
