当用户对车辆的充值、退款、充正的所有记录都可以在充值查询进行查看

<font style="color:rgb(34, 34, 34);">首先，你需要登录智慧停充一体化平台，按照以下路径进入功能页面：</font>

+ **<font style="color:rgb(34, 34, 34);">路径</font>**<font style="color:rgb(34, 34, 34);">：【车辆管理】 -> </font>**<font style="color:rgb(34, 34, 34);">【充值查询】</font>**<font style="color:rgb(34, 34, 34);">。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/67715279/1777370695728-73e3946d-2d67-4ba5-bde1-afd9a40aa553.png)

| 1 | 所属车场 | 默认当前车场 |
| --- | --- | --- |
| 2 | 姓名 |  车主 / 缴费人姓名 |
| 3 | 车牌号 | 默认给车辆操作的车辆 |
| 4 | 计费类型 | 车辆是某种类型此处显示某种计费类型 |
| 5 | 开始日期 | 可在创建车辆设置的开始日期 |
| 6 | 截止日期 | 可在创建车辆设置的截止日期 |
| 7 | 操作类型 | 充值续费、充值、退款 |
| 8 | 缴费数量 |  本次缴费 / 充值的金额或笔数   |
| 9 | 应收金额 | 显示应收的金额明细 |
| 10 | 实收金额 | 显示实收的金额明细 |
| 11 | 支付方式 | 显示操作的支付方式 |
| 12 | 操作时间 | 操作时间平台有数据 |
| 13 | 支付详情 | 支付的操作详细信息都会展示出来 |
| 14 | 操作员 | 显示操作的人员 |
| 15 | 地址 | 显示地址 |
| 16 | 备注 | 补充说明信息，可填可不填   |
| 17 | 业务操作 | 点击操作按钮会展示缴费数量，有效期起、有效期止、管理员、备注 |
| 18 | 导出 | 可导出充值查询的详细信息 |
