#### 一、功能设置
1、<font style="color:rgb(15, 17, 21);">登录管理系统后台，导航至</font>**<font style="color:rgb(15, 17, 21);"> 【车库管理】</font>**<font style="color:rgb(15, 17, 21);"> 模块，找到并点击</font>**<font style="color:rgb(15, 17, 21);"> 【车位限制】 </font>**<font style="color:rgb(15, 17, 21);">功能菜单。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1776927787049-b670cae5-61cf-4849-8865-6c05617481ab.png)

**<font style="color:rgb(15, 17, 21);">A</font>**、**<font style="color:rgb(15, 17, 21);">可停放总数核对</font>**<font style="color:rgb(15, 17, 21);">：确保“新能源车位”与“蓝牌车位”的 </font>**<font style="color:rgb(15, 17, 21);">【可停放数量】</font>**<font style="color:rgb(15, 17, 21);"> 之和，等于车库的 </font>**<font style="color:rgb(15, 17, 21);">【总车位数】</font>**<font style="color:rgb(15, 17, 21);">。</font>

**<font style="color:rgb(15, 17, 21);">B</font>**、**<font style="color:rgb(15, 17, 21);">剩余数量核对</font>**<font style="color:rgb(15, 17, 21);">：确保两类车位的 </font>**<font style="color:rgb(15, 17, 21);">【剩余车位数】</font>**<font style="color:rgb(15, 17, 21);"> 之和，等于车库总的 </font>**<font style="color:rgb(15, 17, 21);">【剩余车位数】</font>**<font style="color:rgb(15, 17, 21);">。</font>

**<font style="color:rgb(15, 17, 21);">C</font>**、**<font style="color:rgb(15, 17, 21);"> 启用状态选择</font>**<font style="color:rgb(15, 17, 21);">：根据实际需要，勾选启用 </font>**<font style="color:rgb(15, 17, 21);">【新能源车】</font>**<font style="color:rgb(15, 17, 21);"> 和/或 </font>**<font style="color:rgb(15, 17, 21);">【蓝牌车】</font>**<font style="color:rgb(15, 17, 21);"> 车位类型。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1776929037893-ecaa23a7-bd77-4ed9-bdeb-aed6b75f846a.png)

**<font style="color:#000000;">注意</font>**<font style="color:#000000;">：请务必完成A、B两项的数量核对，这是避免后续车位数统计出现混乱的关键。如果暂时不需要对某类车进行限制，可在C项中关闭其启用状态。</font>

**2、如需在某一类车位已满时，自动阻止对应车辆入场，需在通道权限中进行如下配置。**

+ <font style="color:rgb(15, 17, 21);">进入</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">【通道管理】</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">或</font><font style="color:rgb(15, 17, 21);"> </font>**<font style="color:rgb(15, 17, 21);">【通行权限】</font>**<font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">设置模块。</font>
+ <font style="color:rgb(15, 17, 21);">找到目标车行入口通道（例如：</font>**<font style="color:rgb(15, 17, 21);">“XXX通道”</font>**<font style="color:rgb(15, 17, 21);">）的配置项。</font>
+ <font style="color:rgb(15, 17, 21);">针对需要限制的车类（例如：当蓝牌车位已满时限制蓝牌车），将其 </font>**<font style="color:rgb(15, 17, 21);">【通行权限】</font>**<font style="color:rgb(15, 17, 21);"> 设置为 </font>**<font style="color:rgb(15, 17, 21);">【否】</font>**<font style="color:rgb(15, 17, 21);"> 或 </font>**<font style="color:rgb(15, 17, 21);">【禁止通行】</font>**<font style="color:rgb(15, 17, 21);">。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1776929250491-e90dee5f-384d-4c83-b38c-1213a68d77e4.png)

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1776929504918-f664850b-85ac-4953-8b71-531596508a5d.png)

<font style="color:rgb(15, 17, 21);">完成上述设置后，当被限制的车辆（如蓝牌车）在对应车位已满时尝试入场，系统将自动触发以下流程：</font>

+ <font style="color:rgb(15, 17, 21);">入口道闸</font>**<font style="color:rgb(15, 17, 21);">不会抬杆</font>**<font style="color:rgb(15, 17, 21);">放行。</font>
+ <font style="color:rgb(15, 17, 21);">岗亭管理电脑上会</font>**<font style="color:rgb(15, 17, 21);">弹出清晰提示框</font>**<font style="color:rgb(15, 17, 21);">，显示 </font>**<font style="color:rgb(15, 17, 21);">“车位已满”</font>**<font style="color:rgb(15, 17, 21);"> 等信息，方便值班人员向车主解释。</font>
