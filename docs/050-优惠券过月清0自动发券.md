**用户限制商户按月发放优惠券次数，优惠次数用完后，需下月才能继续发券优惠**

1、首先新增一个需要限制发放优惠券的商户，填写好相关信息后确认添加商户

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777433758719-bed73655-c8f7-4c4d-a1be-ebebf1dc2301.png)

2、绑定停车券

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777434039603-48e1dc72-0efe-427d-b08e-1e52571e3c97.png)

3、设置发券限制，根据需求设置最大发券次数和其他参数

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1778120511140-ab401f1e-ed78-4d21-9db3-fc8f37d3c737.png)

| 周期限制 | 默认为不启用，目前仅支持按月限制 |
| ---: | --- |
| 最大减免次数 | 根据需求填写商户一个月内可发放的停车券次数 |
| 过期是否重置 | 默认为否<br/>选择否，则过期后最大减免次数会与上个周期剩余次数累加<br/>选择是，则过期后上个周期剩余次数清零重新计算 |
| 修改剩余次数 | 默认为否<br/>选择否，则商户在一个月内使用完发券次数后将不能继续发放优惠券<br/>选择是，则商户使用完发券次数后根据需求修改发放次数后可继续发放优惠券 |
| 剩余次数 | 根据需求修改发券次数<br/>注：此处可修改的前提条件是修改剩余次数需选择是 |


4、商户登录商户平台，在限制次数内发放万优惠券后会提示：本月剩余优惠次数不足

![](https://cdn.nlark.com/yuque/0/2025/png/48964439/1749267560936-531db844-5980-45b6-beaa-4f9409ef3b8e.png)
