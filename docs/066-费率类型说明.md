#### 1,。新增费率基础配置
路径：【车场信息】 -> 【费率管理】 -> 【新增】

在创建新费率时，需先完成基础参数的选择，这些参数适用于所有费率类型。

+ 所属车场/车库：选择该费率适用的车场及具体车库区域。
+ 车类：选择车辆类别（如临时车、月租车、储值车等）。
+ 车型：可选择“不区分”或指定具体车型（如新能源小车）。
+ 费率类型：分为“默认”与“非默认”，用于设置是否为此车类的默认收费方案。



![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776912425172-c66f8c2e-e7d0-4acc-bb9f-fb667f877057.png)![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776912679524-167b81ac-b806-4d2f-b2e3-d8682d1fe33c.png)

+ 参数说明

| 参数名称 | 参数说明 |
| --- | --- |
| 所属车场 | 当前车场名称 |
| 车型 | 默认情况下为“不区分”，可下拉选择具体车型，客户可根据需求设置对应的车型类别 |
| 车类 | 分为六种：临时车、月租车、储值车、免费车、业主临停车等，客户按需选择或新增 |
| 所属车库 | 选择该规则所停放的车库区域，用于便捷管理和归类 |
| 收费类型 | 选择收费的类型：简易不分段收费、累计时间收费、按天分段收费、多段收费设置 |
| 费率类型 | 分为默认、非默认，设置是否默认此收费 |


#### 2.四种费率类型详解
#### 2.1 简易不分段收费
适用场景：规则简单的停车场，按统一标准收费。

+ 核心逻辑：根据车辆累计停放总时间收费，无分段计费。
+ 关键参数：
    - 免费时间：设定入场后的免费时长。
    - 首段时间：超过免费时间后，首段收费时段。
    - 单位时间：首段之后，按每个单位时间（如60分钟）循环收费。
    - 一天单次最大收费：设定24小时内的费用上限。
    - 过夜费：可设置夜间额外收费金额。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776914264524-6bbf3ed4-8e7f-4559-8c23-1f3644bf088c.png)

+ 参数说明

| 1 | 收费类型 | 简易不分段收费, 根据车辆在停车场内累计停放的总时间进行收费的方式，不设分段或不同费率。无论停放多久，都按统一的收费标准计算费用。 |
| --- | --- | --- |
| 2 | 所属车库 | 当前车库名称 |
| 3 | 计费类型 | 分为六种：临时车、月租车、储值车、免费车、业主临停车、时段月租车等 |
| 4 | 车型 | 默认情况下为“不区分”，可下拉选择具体车型 |
| 5 | 一天单次最大收费 | 设定车辆在24小时内的停车费用上限，一旦达到该限额，即使继续停放也不再增加额外费用 |
| 6 | 多次进出限额设置 | 否：每次进出停车场单独计费，不享受一次收费政策。   按自然日区分：在自然日内（即从当天零点到当天24点），无论车辆多次进出，只收取一次费用。   24小时区分：从车辆首次进入停车场开始的24小时内，多次进出只收取一次费用。   12小时区分：从车辆首次进入停车场开始的12小时内，多次进出只收取一次费用。 |
| 7 | 过夜费(元) | 1 过夜费为 0 , 车辆在夜间停放不会产生额外费用，仅计算正常的白天停车费用。   2过夜费设置为某金额 , 车辆在夜间停放时，需要在正常的停车费基础上额外支付指定的过夜费。 |
| 8 | 免费时间 | 车辆免费停车时长，规定时间内，车辆停车不收费 |
| 9 | 首段时间 | 车辆停车超过免费时间后收取费用的时段 |
| 10 | 单位时间 | 车辆停车超过首段时间后，剩余部分时间均按单位时间进行计费 |


#### 2.2 累计时间收费
适用场景：按自然日或24小时周期累计停放时间收费。

+ 核心逻辑：费用基于车辆累计停放的时间计算，支持跨天计费。
+ 关键参数：
    - 跨0点计费类型：选择“计费时间”（实际付费时长）或“基本时间”（包含免费/固定时长）。
    - 最大收费类型：可选“无最大收费”、“按自然日”或“按24小时”封顶。
    - 一天多次最大收费：限制24小时内多次进出的累计最高费用。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776924039927-1b610a4a-55ca-48ce-92b4-3982785443c4.png)

+ 参数说明

| 1 | 收费类型 | 累计时间收费，即根据车辆累计停放的时间进行收费。 |
| --- | --- | --- |
| 2 | 所属车库 | 回显字段 |
| 3 | 计费类型 | 回显字段 |
| 4 | 车型 | 回显字段 |
| 5 | 免费时间 | 即车辆在进入停车场后的免费时间 |
| 6 | 一天单次最大收费 | 车辆在一天（24小时）内单次进入停车场的最高收费 |
| 7 | 过夜费(元) | 两种规则：   1、过夜费为 0 , 车辆在夜间停放不会产生额外费用，仅计算正常的白天停车费用。   2、过夜费设置为某金额 , 车辆在夜间停放时，需要在正常的停车费基础上额外支付指定的过夜费。 |
| 8 | 跨0点计费类型 | 两种类型：   1、计费时间： 是实际需要付费的时长，直接决定最终的费用。    2、基本时间： 是包含在服务中的免费或固定时长，只有超出部分才会进入计费时间的计算。（ 管理员根据实际情况选择适合的基本时间类型，并调整相应的参数（如免费时长、优惠金额等）。停车场能够根据不同的运营策略来调整收费规则，以更好地服务不同的用户群体 ） |
| 9 | 最大收费类型 | 三种类型：   1、无最大收费： 费用没有上限，完全按标准规则计算。    2、按自然日： 每日（自然日）费用设有上限，不超过设定金额。   3、按24小时： 每24小时周期内的费用有封顶，超过周期重新计算。 |
| 10 | 一天多次最大收费 | 一天（24小时）内车辆多次进出停车场的累计最高收费标准 |
| 11 | 类型 | 两种类型：   1按整点（小时为单位）   2按半点（小时为单位） |


#### 2.3 按天分段收费
适用场景：需区分白天、夜间不同费率的场景。

+ 核心逻辑：将24小时划分为两个时段（如日间7:00-19:00，夜间19:00-7:00），各时段独立计费。
+ 关键参数：
    - 开始时间：分别设置时段一和时段二的起止时间。
    - 免费/首段/单位时间：每个时段可独立设置免费时长、首段收费及循环单位。
    - 注意：系统取值逻辑特殊，配置时需注意第一段与第二段免费时间的设置位置可能相反。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776925032796-b6327d8f-2530-4a1e-9720-521c14959f17.png)

+ 参数说明

| 1 | 收费类型 | 按天分段收费， 适用于需要区分白天、夜间或不同天数收费标准的场景。 |
| --- | --- | --- |
| 2 | 所属车库 | 回显字段 |
| 3 | 计费类型 | 回显字段 |
| 4 | 车型 | 回显字段 |
| 5 | 收费类型 | 按24小时单次进出 |
| 6 | 一天最大收费 | 一天（24小时）内车辆多次进出停车场的累计最高收费标准 |
| 7 | 开始时间 | 分别设置一，二段的开始时间。 <br/> ●日间时段（例如：早上7:00到晚上19:00），按一个费率收费。   <br/> ●夜间时段（例如：晚上19:00到次日早上7:00），按另一个费率收费。 |
| 8 | 免费时间 | 第一段免费时间与第二段免费时间不一致时，需把第一段的免费时间设置在第二段免费时间处，第二段需设置在第一段免费时间处，因现系统中取值是反的 |
| 9 | 首段时间 | 首段时间内的停车收费按照首段设定的费率标准计算。 |
| 10 | 单位时间 | 车辆每累计停满一个每小时（60分钟）的计费标准 |
| 11 | 跨段计费类型 | 现只有按单位时间计算 |


#### 2.4 多段收费设置
适用场景：复杂的分时段收费（如工作日/非工作日、早中晚高峰）。

+ 核心逻辑：支持最多4个时段的精细化设置，默认启用2个时段。
+ 关键参数：
    - 收费类型：可选“工作日”或“非工作日”。
    - 时段设置：灵活添加/删除时段，设置各时段的“起步时间”、“起步循环”及“循环时段”费用。
    - 跨天/补时：可配置跨越时段时是否享有免费时间、基本计费或补时规则。
    - 限额：支持设置“当日最大收费”及“一天多次最大收费”。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1776927643097-dd748433-9b63-414e-9784-0ac7be5cd6eb.png)

+ 参数说明

| 1 | 收费类型 | 多段设置收费，用于设定不同时间段内的不同收费标准。（默认启用两个时间段，常见的设置包括日间和夜间两个时段，也可以根据需求增加至最多4个不同的时段，如早晨、白天、晚间、夜间 ，或是高峰时段和非高峰时段的不同收费标准 ） |
| --- | --- | --- |
| 2 | 所属车库 | 回显字段 |
| 3 | 计费类型 | 回显字段 |
| 4 | 车型 | 回显字段 |
| 5 | 收费类型 | 两种类型：<br/>1工作日  <br/>2非工作日 |
| 6 | 最大收费类型 | 三种类型：<br/>1无最大收费 <br/>2按24小时（兼容节假日）   <br/>3按24小时 |
| 7 | 当日最大收费 | 默认为0（0代表不限额） |
| 8 | 一天多次最大收费 | 默认为0（0代表不限额），一天（24小时）内车辆多次进出停车场的累计最高收费标准 |
| 9 | 跨度段是否有免费时间 | 表示车辆在跨越不同收费时段时，是否有免费停放时间 |
| 10 | 跨度段是否有基本计费 | 表示车辆在跨越不同收费时段时，是否按起步时段计费费用 |
| 11 | 跨度段是否补时 | 表示车辆在跨越不同收费时段时，是否按起步时段计费费用 |
| 12 | 跨天是否按段计费 | 表示车辆跨越一天的时间段时，是否按照各自时间段的收费规则分别计费 |
| 13 | 起步时段 | 表示首次收费的时间间隔 |
| 14 | 起步循环 | 表示在首次收费后的循环收费周期 |
| 15 | 循环时段 | 表示在起步循环后的循环收费周期 |
| 16 | 时段限额 | 表示在该收费时段内的最高收费金额 |
