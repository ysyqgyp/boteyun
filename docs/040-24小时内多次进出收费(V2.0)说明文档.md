#### 一、24小时内多次进出收费版本
**1、操作路径**

车场平台 → 车场信息 → 我的车场 → 基本参数 → 进出场参数

**（注：新建项目默认规则V2.0版本--新回滚计费规则(出场节点)）**

**2****、启用与选择计费模式**

(1)、启用新版本：在“24小时内多次进出收费版本”处，选择 “2.0版本”。

(2)、选择具体模式：启用后，下方“24小时内多次进出计费模式”选项，您可根据运营需求选择以下任一模

            + **按重叠时间计算**：<font style="color:#080f17;">以车辆</font>**<font style="color:#080f17;">第一次入场时间</font>**<font style="color:#080f17;">为起点，向后推算</font>**<font style="color:#080f17;">24小时</font>**<font style="color:#080f17;">为一个完整计费周期</font>。
            + **按重叠时间计算-24小时内收费不超过一天多次最大收费**：在重叠计费基础上，增加24小时内的累计费用封顶。
            + **按重叠计费-只收取一个起步费用**：在重叠计费基础上，增加24小时内的累计费用封顶，并且对24小时内跨天单次停车只收取一个起步费用，后续仅计重叠时长。
            + **新回滚计费规则(出场节点)**：此为**V2.0版本的默认模式**。以出场时间为基准，回溯24小时合并计算，并执行费用封顶等复杂规则。

**3、操作结果**

保存后，车场的24小时内多次进出计费将按您选择的模式执行。

#### 二、24小时内多次进出计费模式
**1、新回滚计费规则(出场节点)**

**核心概念与流程**

本规则用于处理车辆出场时，其历史停车记录跨越计费周期的情况。核心思想是：拆分、重算、校验、封顶，以确保在24小时回滚窗口内计费公平且符合封顶规则。

**（1）、 回滚周期定义**

        * 以车辆**出场时间（T）** 为基准，向前回溯24小时（T-24），此固定窗口即为本次结算的计费周期。
        * 系统将查找并处理此窗口内所有停车记录。

**（2）、跨段记录拆分流程**

当存在开始时间早于周期起点（T-24）的“跨段”记录时（如图示A段），系统将执行以下拆分与重算流程，

如下图：把跨段停车时段A拆分为时段C(26号12点到27号17点)，并重新计算C的费用，且不 包含首小时计费，得出：D的时段费用<=全天最高收费-C时段的费用-B的时段费用

以图示场景为例：

**A段**：26日06:00 – 26日17:00（跨段，需拆分）

**B段**：26日18:00 – 26日20:00（独立时段）

**C段**：由A段拆分出的子段 → 26日12:00 – 26日17:00（重算回滚计费段）

**D段**：27日08:00 – 27日12:00（独立时段，费用为：D的时段费用<=全天最高收费-C时段的费用-B的时段费用）

目标：重新计算 **C段费用**，结合 B、D 段，确保总费用 ≤ 全天最高限价，同时遵循历史回滚一致性原则。

示例图：

![](https://cdn.nlark.com/yuque/0/2025/png/25745394/1765360350753-31e65238-b486-48ab-a9bc-4defc2e34d24.png)

**（3）、C段拆分计费四大规则（回滚核心逻辑）**

  对从跨段记录A中拆分出的、位于回滚周期内的C段（如图示 `26日12:00–17:00`），必须按以下规则独立重新计费：

| 规则 | 名称 | 具体内容与要求 |
| :--- | :--- | :--- |
| 规则1 | 免优豁免 | C段计费时：<br/>1. 不享受任何免费时长（如首30分钟免费）。<br/>2. 不适用任何首时段特殊计费（如首小时优惠）。<br/>目的：避免跨段停车在拆分后重复享受周期“起点”优惠。 |
| 规则2 | 采用最新费率 | C段强制采用本次回滚周期内最新生效的收费规则（通常以D段所用规则为准）。<br/>目的：确保费率一致性，以结算时刻的最新标准进行历史回溯计算。 |
| 规则3 | 独立记录处理 | C段被视为一条全新的虚拟停车记录：<br/>1. 独立计费，不继承原A段的任何折扣、优惠券、会员减免等。<br/>2. 不参与原A段的支付状态。 |
| 规则4 | 费用上限保护 | 核心原则：回滚不增费。<br/>C段重新计算出的费用，不得超过原A段的实际收费金额。若超出，则强制采用原A段费用作为C段值。<br/>目的：维护用户权益与历史数据稳定性，防止拆分导致费用增加。 |


**（4）、全局费用校验与封顶**

所有分段费用重算后，必须通过全局校验，确保符合周期封顶政策。

A、校验公式

【C段重算费用】 + 【B段实际费用】 + 【D段实际费用】 ≤ 全天最高限价（14元）

B、封顶调整策略（当校验不通过时）

若以上总和超过14元，系统应优先保障总费用不超封顶，建议采用以下可配置策略之一：

策略一（推荐）：按比例下调D段的费用，因C段费用已在规则4下被压缩。

基础计费规则--示例

        * 免费时长：30分钟。
        * 首段时间：30-60分钟：收费5元。
        * 计费时间：60分钟后：每60分钟收费1元，不足60分钟按60分钟计算
        * 单次最高收费：10元。
        * 24小时内多次进出最高收费：14元

**2、按重叠时间计算**

**（1）、核心条件与基础规则**

计费周期：以车辆第一次入场时间为起点，向后推算24小时为一个完整计费周期。

跨天：指单次停车时长跨越一个完整的计费周期边界。

    - 基础计费规则（适用于单个计费周期内）--示例
        * 免费时长：30分钟。
        * 首时段：30-60分钟，收费5元。
        * 后续计费：60分钟后，每满60分钟收费1元，不足60分钟按60分钟计算（即向上取整）。
        * 费用封顶：
            + 单次停车最高收费10元；
            + 同一车辆24小时（计费周期）内多次进出，累计最高收费10元。

**（2）、跨天（完整24小时）处理规则**

当一次停车时长跨越一个完整的24小时计费周期时，适用以下规则：

    - 情况一：跨天按首段时间

若系统设置为“跨天按首段时间”，则在新的24小时周期开始时，重新按首时段规则（30-60分钟收费5元）开始计费

    - 情况二：跨天按计费时间

若系统设置为“跨天按计费时间”新周期不重置，直接延续按“计费时间（1元/60分钟）”的单价累计

    - 情况三：特殊逻辑（关键例外）

若系统设置为“跨天按计费时间”，但前一个24小时周期内的停车费用为0元（例如，仅停留了免费时长），则在新的周期开始时，需额外加收一个首段费用（5元）

**3、按重叠时间计算-24小时内收费不超过一天多次最大收费**

**（1）、 核心逻辑**

本模式在“重叠时间计费”基础上，增加24小时周期内累计费用封顶规则。系统以车辆第一次入场时间为起点，计算后续24小时为一个完整计费周期，并确保该周期内所有停车费用总和不超过设定的“一天多次最大收费”金额。

【重要注意事项：跨天单次停车的封顶处理】

请注意，即使车辆只是单次停车，只要其停车时长不足24小时但发生了跨天，本次停车所涉及的所有费用（分别按前后周期的规则计算）在累加后，也受 “24小时内多次进出最高收费” 限制

**（2）、基础计费规则（单次停车）--示例**

        * 免费时长：30分钟。
        * 首时段（30-60分钟）：收费5元。
        * 计费时间（60分钟后）：每60分钟收费1元，不足60分钟按60分钟计算。
        * 单次停车最高收费：10元。
        * 24小时内多次进出最高收费：10元（此为周期内的总费用上限）。

**（3）、跨天（完整24小时周期）处理规则**

当单次停车时长跨越一个计费周期（24小时）时，根据以下设置进行处理：

    1. 设置A：跨天按首段时间
        * 逻辑：进入新的24小时周期后，计费规则完全重置，从“首时段”（30-60分钟，5元）重新开始计算。
    2. 设置B：跨天按单位时间
        * 逻辑：进入新的24小时周期后，不再享受“首时段”优惠，而是直接按“计费时间”的费率标准，以1小时为单位进行累加（即每60分钟1元，不足按60分钟计）。

**（4）、重要条件与约束**

    1. 周期定义：计费周期始终以车辆第一次入场时间为起点，向后推算24小时，不受自然日影响。
    2. 封顶机制：在一个计费周期内，无论进出多少次，累计收取的总停车费不会超过“24小时内多次进出最高收费”（即10元）。系统会在累计费用达到此上限后自动停止计费。

**4、按重叠计费-只收取一个起步费用**

**（1）、 模式核心与周期定义**

        * 核心原则：在一个滚动的24小时计费周期内，以车辆第一次入场时间为周期起点。在一个完整的24小时周期内，单次停车仅收取一次首段时间费用，超出部分按单位时间计费。
        * 周期定义：计费周期为滚动（滑动）的24小时窗口。首个周期始于车辆第一次入场时间，后续每个周期均紧接上一周期结束的节点开始。

【重要注意事项：跨天单次停车的封顶处理】

请注意，即使车辆只是单次停车，只要其停车时长不足24小时但发生了跨天，本次停车所涉及的所有费用（分别按前后周期的规则计算）在累加后，也受 “24小时内多次进出最高收费” 限制

**（2）、 基础计费规则-示例**

        * 免费时长：30分钟。
        * 首段时间（起步费）：30-60分钟，收费5元。
        * 单位时间费率：60分钟后，每60分钟收费1元，不足60分钟按60分钟计算。
        * 费用封顶：
            + 单次停车最高收费：10元。
            + 24小时内多次进出最高收费：10元（此为每个滚动周期的总费用上限）。

（3）、单周期内计费规则

        * 在任意一个24小时周期内，单次停车仅收取一次“首段时间费用”。超过首段时间均按“单位时间”费率计费。

（4）、跨周期计费逻辑

当单次停车跨越一个周期节点时，系统将根据前一周期的收费状态，自动判定新周期的计费起点：

| 前一周期状态 | 新周期计费起点 |
| :--- | :--- |
| 已收取起步费 | 直接按 “单位时间费率” 开始累计 |
| 未收取起步费<br/>（如仅停满免费时长） | 先收取一次 “首段时间费用” ，再按“单位时间费率”累计 |


**（5）、 费用封顶执行**

系统实时累计车辆在当前滚动周期内的所有费用。一旦累计额达到“24小时内多次进出最高收费”（10元），该周期内后续产生的任何费用将自动免除。
