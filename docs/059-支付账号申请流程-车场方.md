#### 步骤一：提交申请资料
目前提交申请有两种提交方式：一个是在我们停车平台上提交，另一个是用我们技术支持人员提供文档来提交申请信息，（更推荐后者）

[对公支付车场进件表模板.docx](https://www.yuque.com/attachments/yuque/0/2026/docx/67715238/1778221049187-9f998daa-99ba-4d6a-aa72-5b121a7b5ecc.docx)

[对私支付车场进件表模板.docx](https://www.yuque.com/attachments/yuque/0/2026/docx/67715238/1778221049329-22d4c041-97ce-4532-922d-423e62a3c71b.docx)

**在停车平台申请操作如下：**

登录服务商账号后，根据车场编号找到我们要申请支付的车场，点击申请支付按钮，获取申请支付的二维码，

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777518836402-dc0802e5-c085-4b15-94e1-655d56f8cbcf.png)

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777518866362-330d547c-ab9b-4f4d-b2a1-b32574392da5.png)

| 参数 | 说明 |
| :---: | :---: |
| 聚合支付 | 聚合支付指的是支持微信，支付宝，银联等日常常用支付方式，也是目前我们最推荐的支付方式 |
| 微信支付 | 是指收款后直接提现到指定的微信账号 |
| 支付宝支付 | 是指收款后直接提现到指定的支付宝账号 |
| P云支付 | 扫码后填写的支付申请信息回直接提交到P云平台，将不再需要我们泊特技术支持人员审核，目前不推荐该种方式，对我们后期维护产生较大工作量。 |


点击手机端进件，得到我们申请支付的二维码

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777518956176-e67e2d57-a0b8-4618-9033-dfeab67183e9.png)

二维码如下图，分为对公和对私两种支付方式，对公的二维码针对的是企业或集体用户，对私的是针对个人用户。根据实际情况扫码即可。

注：目前对公的账号可以先使用再签约，但是一定要签约，不然会影响后续使用，对私的账号一定要先签约才能使用，签约后需告知群里的技术支持人员，进行绑定车场后才能正常使用。

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519018120-e55557bb-8dea-44bc-96f8-56f5974499be.png)

**1、对公支付申请信息填写**

扫码将进入支付信息填写页面：

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519161073-b4f8e122-4cb8-4cc6-9089-ce39e682a129.png)

| 参数 | 说明 |
| :---: | :---: |
| 车场简称 | 会自动识别到生成支付申请二维码的车场 |
| 营业执照照片 | 大小不能超过2MB |
| 营业执照名称 | 需与营业执照一致 |
| 营业执照编号 | 需与营业执照一致 |
| 详细地址 | 需与营业执照一致 |


![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519328752-d5b58012-5130-42c4-8dce-e972d1a6b2fb.png)

| 参数 | 说明 |
| --- | --- |
| 经办人名字 | 这个经办人会是签约人 |
| 经办人手机号 | 签约电子合同时需验证手机号码，并且在首次登录支付平台是需要用该手机号码进行密码重置 |
| 经办人邮箱 | 可不填 |
| 经办人身份证号码 | 签约是需要验证签约人的身份证号码 |
| 客服手机号 | 用于处理车场运营问题，可以是座机号或者手机号 |


![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519395859-1338e4c4-0448-4aa7-97eb-49a8cc84eea0.png)

| 参数 | 说明 |
| :---: | :---: |
| 银行卡账号 | 填写企业名下的银行卡账号 |
| 开户银行 | 根据实际情况填写 |
| 开户名称 | 根据实际情况填写，要填写全称 |
| 开户所在省市 | 要和营业执照一致 |


![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519458655-bb18a12a-6238-4b1a-bcff-42db35891ba4.png)

| 参数 | 说明 |
| :---: | :---: |
| 身份证人像面 | 1.请上传彩色照片、彩色扫描件或加盖公章鲜章的复印件。要求正面拍摄，确保证件四角清晰、完整，所有字符清晰可识别，无反光或遮挡。不得进行翻拍、截图、镜像或使用 Photoshop 进行修改。2. 图片仅支持 JPG、BMP 或 PNG 格式，文件大小不得超过 1M。 |
| 身份证国徽面 | 1.请上传彩色照片、彩色扫描件或加盖公章鲜章的复印件。要求正面拍摄，确保证件四角清晰、完整，所有字符清晰可识别，无反光或遮挡。不得进行翻拍、截图、镜像或使用 Photoshop 进行修改。2.图片仅支持 JPG、BMP 或 PNG 格式，文件大小不得超过 1M。 |
| 法人号码 | 法人的电话号码 |


![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777519588873-665efe42-2f1a-421c-8f51-9758a9970016.png)

| 参数 | 说明 |
| :---: | :---: |
| 停车场出入口照片 | 目前没有强制要求提供，如果不提供，技术人员将上传空白照片到支付平台 |
| 停车场内部照片 | 目前没有强制要求提供，如果不提供，技术人员将上传空白照片到支付平台 |
| 开户许可证照片 | 1.提供收款商户在银行开户银行颁发的开户证明，若无银行开户证明请上传最近一笔交易回执单(敏感金额打码)体现收款方开户银行和收款账号即可。<br/>2.需正面拍摄，露出证件四角且清晰、完整，所有字符清晰可识别，不得反光或遮挡。不得翻拍、截图、镜像、PS.<br/>3.图片支持JPG、BMP、PNG格式，文件大小不能超过1M。 |
| 收费公示牌照 | 目前没有强制要求提供，如果不提供，技术人员将上传空白照片到支付平台 |
