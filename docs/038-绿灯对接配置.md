### <font style="color:#DF2A3F;">绿灯对接是停车场的月租车位信息租给绿灯平台，绿灯平台根据同步的车位信息，租给外来车等，该对接仅限于大小场</font>
# 1.服务商配置绿灯对接
服务商选择车场-参数配置-配置参数-选择绿灯对接

![](../assets/thumbs/205.jpg)

配置参数

1.配置平台：绿灯停车

2.appId：由绿灯技术提供  
3.parkUuid：无需填写  
4.是否启用：是  
5.API地址：由绿灯技术提供  
6.<font style="color:rgb(0, 0, 0);background-color:rgb(251, 251, 251);">app_id：由绿灯技术提供  
</font><font style="color:rgb(0, 0, 0);background-color:rgb(251, 251, 251);">7.app_secret：由绿灯技术提供</font>
