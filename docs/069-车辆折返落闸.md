#### 注：车辆折返落闸分两种情况-->入口折返和出口折返，如下表格：
|  | 入口折返 | 出口折返（产生费用） | 出口折返（不产生费用） |
| :---: | :---: | :---: | :---: |
| 入场记录 | 无 | 无 | 有 |
| 出场记录 | 无 | 有 | 无 |
| 折返记录 | 有 | 无 | 有 |
| 在场记录 | 无 | 有 | 有 |
| 停车时长计算方式 | 不计 | 按原来入场时间开始算 | 按原来入场时间开始算 |
| 车位数 | 不变 | 减一 | 减一 |


#### 入口折返
入口折返是指车辆在入口处时，车牌识别机已经识别到车牌，但车辆并未入场。这时如果相机已启用折返事件的功能就可以检测到车辆的运动轨迹，从而判断出车辆并未入场同时在停车管理平台上并不会有这辆车的入场记录。

步骤一：在相机中配置启用折返，滞留，跟车事件<font style="color:#DF2A3F;">（目前只支持臻识的R5,R5L）</font>

**点击高级设置→识别设置模块→选择车辆检测**

#### 出口折返
出口折返分两种情况

需要缴费的情况下车辆折返，车辆不会再有入场记录，不会产生一条折返记录，等再次出场时会去匹配基础参数里的未找到入场记录支付金额

不需要缴费的情况下车辆折返，车辆不会有出场记录，只会产生一条折返记录，并且停车时长是从首次进场时间开始计算，不会从折返时间再开始计算。
