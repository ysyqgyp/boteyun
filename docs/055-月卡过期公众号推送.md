#### 一、新增参数
1、点击我的车场->高级参数->新增

![](../assets/thumbs/738.jpg)

A、 参数类型----月卡过期公众号推送

B 、剩余天数---在选择开始日期之后，例如：此处选择5天，也就是月租车还有5天就到期就进行公众号推送，

C 、开始日期---开始日期选择后，剩余天数内每天间隔天数推送

D 、间隔天数---例如：此处选择1天，也就是隔1天就推送过期信息提醒车主 

<font style="color:rgb(255,0,0);">例子：开始时间选的2026.04.29 ，剩余天数10天，那么2025.04.29-05.04之内的日期不会推送（当天日期为2025.04.08）</font>

注意：每天10.30分定时推送，每天推送一次

2、关注公众号

微信搜索壹家社区公众号进行关注，然后将车辆绑定到公众号或者小程序

![](../assets/thumbs/739.jpg)

公众号绑定车辆:点击我的车辆-绑定车辆-输入车牌即可
