#### 1、定位并选择商户
**（1）、登录服务商后台**

**（2）、进入【商户管理】模块**

权限说明：此处只能查询并管理 本服务商直接管辖的车场下的商户。下级服务商所辖车场内的商户无法在此看到。

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777261407960-1eb38bbe-ea08-45a6-b186-408f26d121aa.png)

#### 2、为商户绑定目标车场
**（1）、  在目标商户的操作列、点击【绑定车场】**

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777261436824-245b9907-07bf-4a0c-8784-699bc72d36b0.png)

**（2）、 在****<font style="color:rgb(15, 17, 21);">弹出的车场列表中，勾选该商户需要提供优惠的目标车场（可多选），并确认。</font>**

**场景示例：**比如登录 通用优惠券车场1 的商户，此处绑定了通用优惠券车场2，那么车场1的商户即可给予车场2的车辆进行优惠。

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777261597635-267de38e-637b-4fc1-9c88-86888a1503c3.png)

#### 3、<font style="color:rgb(15, 17, 21);">商户发起优惠操作</font>
<font style="color:rgb(15, 17, 21);">（1）、被绑定权限的商户登录其账户。</font>

<font style="color:rgb(15, 17, 21);">（2）、在优惠减免操作界面，选择或输入车牌号进行减免。</font>

![](https://cdn.nlark.com/yuque/0/2026/png/67715238/1777267984794-f1b5e36a-17a8-4d71-83e7-69230d4d15d2.png)

#### 4、减免成功生成优惠明细
<font style="color:rgb(15, 17, 21);">优惠成功后，系统会生成优惠明细，但不同角色的查看权限不同：</font>

| <font style="color:rgb(15, 17, 21);">查看角色</font> | <font style="color:rgb(15, 17, 21);">可查看的记录范围</font> | <font style="color:rgb(15, 17, 21);">说明</font> |
| :---: | --- | --- |
| <font style="color:rgb(15, 17, 21);">服务商</font> | <font style="color:rgb(15, 17, 21);">仅显示</font><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">因绑定关系而产生的跨车场优惠明细</font><font style="color:rgb(15, 17, 21);">。</font> | <font style="color:rgb(15, 17, 21);">例如：车场1的商户优惠了车场2的车辆，</font><font style="color:rgb(15, 17, 21);">此记录服务商可见</font><font style="color:rgb(15, 17, 21);">。商户优惠其本车场（车场1）的车辆，此记录服务商后台</font><font style="color:rgb(15, 17, 21);">不显示</font><font style="color:rgb(15, 17, 21);">。</font> |
| <font style="color:rgb(15, 17, 21);">车场平台</font> | <font style="color:rgb(15, 17, 21);">显示</font><font style="color:rgb(15, 17, 21);"> </font><font style="color:rgb(15, 17, 21);">在该车场内产生的所有优惠明细</font><font style="color:rgb(15, 17, 21);">。</font> | <font style="color:rgb(15, 17, 21);">优惠记录与停车记录所在车场一致，停车发生在哪个车场，相应的优惠记录就归属哪个车场的平台。</font> |
| <font style="color:rgb(15, 17, 21);">通用规则</font> | <font style="color:rgb(15, 17, 21);">对于商户</font><font style="color:rgb(15, 17, 21);">未绑定</font><font style="color:rgb(15, 17, 21);">的车场，服务商后台</font><font style="color:rgb(15, 17, 21);">不会生成</font><font style="color:rgb(15, 17, 21);">任何优惠记录。</font> |  |


**场景示例：**如车场1的商户优惠车场2的车辆，那么这台车辆的优惠明细才会在服务商页面展示，但不会展示车场1的优惠明细。车场平台页面-优惠都能展示，停车记录在哪  生成的记录就在哪）

**注意：未绑定的车场 ，服务商页面不会生成记录**

#### 5、核心规则与特殊情况处理
**<font style="color:rgb(15, 17, 21);">  （1）、同车牌在多车场的优惠优先级</font>**

<font style="color:rgb(15, 17, 21);">当同一车牌在不同车场均有车辆入场记录时，优惠对象遵循以下规则：</font>

**<font style="color:rgb(15, 17, 21);">A、未绑定的车场</font>**<font style="color:rgb(15, 17, 21);">：商户只能优惠</font>**<font style="color:rgb(15, 17, 21);">本商户所在车场</font>**<font style="color:rgb(15, 17, 21);">的车辆。</font>

**<font style="color:rgb(15, 17, 21);">B、已绑定的车场（公云环境）</font>**<font style="color:rgb(15, 17, 21);">：系统默认优惠该车牌</font>**<font style="color:rgb(15, 17, 21);">最新的入场记录</font>**<font style="color:rgb(15, 17, 21);">所在的车辆。</font>

**<font style="color:rgb(15, 17, 21);">C、已绑定的车场（私云环境）</font>**<font style="color:rgb(15, 17, 21);">：系统优先优惠该商户</font>**<font style="color:rgb(15, 17, 21);">本身所在车场</font>**<font style="color:rgb(15, 17, 21);">的车辆；若无，则优惠其他已绑定车场的车辆。</font>
