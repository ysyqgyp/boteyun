#### 1、准备工作：在接收方平台创建车场
首先，你需要登录到目标接收数据的平台（即新平台），并创建一个新的车场项目。

+ 操作位置：新平台的项目管理或车场管理模块。
+ 关键信息：记录下新创建车场的项目名称（如“泊特科技迁移”）、项目编号（即新车场ID）、通讯码以及账号密码。这些信息在后续连接步骤中必须使用

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1777430451204-066f099b-084e-4c72-953c-0b51439e60a5.png)

#### 2、登录源平台并进入迁移界面
+ 操作路径：在旧平台的车场列表中，找到目标车场（如“泊特科技有限公司停车场”），点击进入其管理后台。
+ 触发迁移：在后台菜单中找到【超管操作】选项，然后点击子菜单中的【项目迁移】

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1777429155946-d767938b-26af-4e64-b171-a0e1dbc67d34.png)

#### 3、建立平台连接
在【项目迁移】界面中，你需要填写接收方（新）平台的车场信息，以建立两个平台之间的连接。

+ 填写参数：
    - 迁入平台：选择目标平台类型（如“VIP青葱”或对应的新平台名称）。
    - 新车场ID：填入步骤1中记录的新车场项目编号。
    - 新车场通讯码：填入新平台车场的通讯码。
    - 新车场账号/密码：填入新平台车场或所属服务商的登录凭证。
+ 执行连接：填写完毕后，点击【连接】按钮。界面显示“已连接”或状态变为成功后，方可进行下一步

#### ![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1777430807565-eeb938ac-99cc-4413-bb86-4c648e758a0c.png)
| 迁入平台 | 选择需要接收数据的平台 |
| --- | --- |
| 新车场ID | 接收数据车场的ID |
| 新车场通讯码 | 接收数据车场的通讯码 |
| 新车场账号 | 接收数据车场的账号或所属服务商的账号 |
| 新车场密码 | 接收数据车场的密码或所属服务商的密码 |


#### 4、同步数据
连接成功后，即可开始同步数据。系统通常要求先同步基础参数

+ 验证成功：每点击一个同步按钮后，系统通常会提示“重发命令已发送”或在操作日志中显示“执行成功”，表示该类数据已同步至新车场。

#### 5.验证迁移结果
数据同步完成后，登录到接收方（新）平台，进入车场的车辆管理模块进行核对。

+ 检查内容：确认月租车列表、在场车记录、商户信息等是否已完整出现在新系统中。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1777431428830-63e2cbb1-fcc4-485b-b5ac-b823d558f3c0.png?x-oss-process=image%2Fcrop%2Cx_0%2Cy_0%2Cw_1905%2Ch_873)

#### 6.关键提示
1.初次同步：该迁移功能主要适用于初次数据同步。如果数据已经同步过，请勿再次重复操作，以免造成数据混乱。

2.顺序要求：务必遵循“先基础参数，后其他数据”的同步顺序，否则可能导致同步失败或数据缺失。

3.信息准确：在填写接收方车场ID、通讯码和账号时，请务必仔细核对，确保无误。
