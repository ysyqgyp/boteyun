#### 1.系统登录
首先，通过微信小程序访问系统并完成身份验证。

+ 小程序名称：在微信中搜索并进入 “壹家云值守”。
+ 账号获取：登录账号与密码需在“值守平台”的【值守管理】 -> 【值守人员管理】模块中创建。
+ 登录方式：
    - 账密登录：输入分配的值守账号和密码。
    - 手机号快捷登录：通过绑定的手机号接收验证码登录。

#### 2.报警处理与异常处置
当车主通过现场设备发起呼叫或设备触发报警时，小程序会收到提醒。

+ 报警页面：首页会显示待处理的报警信息，包括车场名称、通道、报警时间及设备状态（如离线、报警）。
+ 操作选项：
    - 取消报警：若车主误触或问题已解决，点击“取消报警”停止警报。
    - 处理异常：点击进入异常通道详情页，进行远程干预。

核心操作面板（处理异常时）

+ 视频监控：点击“相机视频”查看车牌特写，“环境监控”查看车道全景。
+ 可视对讲：点击“可视对讲”与车主进行视频通话（需提前在通道配置中开启）。
+ 设备控制：
    - 开闸/落闸：远程控制道闸升降。
    - 重新抓拍：刷新车辆识别信息。
    - 手动入场/取消入场：处理入场异常。
+ 完结工单：操作完成后点击【处理完成】，并选择对应的报警原因归档。

![](../assets/thumbs/553.jpg)

+ 取消报警：车主操作报警服务后值守人员微信收到车辆报警提醒，进入向程序后点击取消报警后即可停止报警；

![](../assets/thumbs/554.jpg)

+ 处理异常：点击马上处理跳转到异常通道，根据车主反馈原因在页面可对该通道进行落闸、开闸、重新抓拍车辆、取消车辆入场操作；

![](../assets/thumbs/555.jpg)

#### 3.车场巡查
值守人员可主动发起对通道的检查。

+ 功能入口：底部菜单栏【车场巡查】。
+ 操作流程：选择目标车场与通道，发起主动连接，实时查看现场画面，确认设备运行状态。

![](../assets/thumbs/558.jpg)

#### 4.个人中心与设置
在【我的】模块中，可进行个人信息维护及系统偏好设置。

+ 上下班状态：设置“值守在线”或“值守离线”，决定是否接收报警。
+ 消息提醒设置（关键）：
    - 订阅推送：进入【消息提醒】 -> 【订阅微信消息推送】，确保能收到报警声音。
    - 通知管理：在微信设置中开启“接收通知”，并确保“车辆报警提醒”设置为“接收并提醒”。
+ 工单记录：根据时间查询历史处理记录，支持复盘与统计。
+ 账号安全：支持修改登录密码及绑定微信通话设备。
