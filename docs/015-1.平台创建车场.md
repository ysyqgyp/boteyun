#### 1.进入新增项目页面
首先，登录服务商账号，进入项目管理模块，填写基础信息。

+ **操作路径**：登录系统 -> 点击【项目管理】 -> 点击【新增项目】按钮。
+ **界面确认**：进入“新增项目”表单页面，准备填写车场信息。

![](https://cdn.nlark.com/yuque/0/2026/png/48964439/1779262193395-7dc0e04b-068d-4521-8738-e690e375c1a5.png)

| 项目类型 | 选择项目类型，如果项目仅有停车平台勾选停车平台即可 |
| --- | --- |
| 项目名称 | 根据实际项目名称填写 |
| 系统类型 | 系统类型根据现场情况选择，纯云端：由设备直接上云与平台连接（设备需要连接外网），一般应用于网络较好场景；半云端：需要本地有一台电脑作为服务器与平台连接（服务器电脑需要连接外网，设备需要与服务器电脑同一个局域网），一般用于网络一般场景 |
| 总共停车位 | 根据现场实际车位数填写（无强制准确性） |
| 地址 | 地址可以在搜索框输入搜索车场地址选择后会自动填入（地址，区/县，省，市，经度，纬度） |
| 负责人 | 根据现场实际管理人员信息填写 |
| 所属服务商 | 当车场所属本服务商时选择无服务商即可，如车场所属下级服务商时可选择对应的服务商 |
| 所属物业 | 当车场无需使用物业账号时选择当前服务商默认物业即可，如车场需物业账号管理多个车场时可先在物业管理创建物业账号，选择对应的物业即可 |
| 有效期至 | 此有效期是限制车场登录平台的有效期，默认可不填写 |
| 项目类型 | 根据项目的场地性质选择对应的类型 |
