#### 1.获取声网认证参数 (AppID & AppSecret)
![](../assets/thumbs/523.jpg)![](../assets/thumbs/522.jpg)

在登录值守后台前，需先在声网官网获取必要的开发凭证。

+ 注册与认证：访问声网官网注册账号，并完成实名认证。
+ 创建项目：
    1. 登录后，进入【设置】->【项目管理】->【创建项目】。
    2. 项目类型：选择“通用项目”。
    3. 项目名称：根据实际需求填写（如“泊特科技”）。
    4. 场景标签：根据业务需求选择（如“1v1 语音”或“视频”）。
+ 获取参数：项目创建成功后，系统会自动生成 AppID 和 AppSecret。请妥善保存这两个参数。

![](../assets/thumbs/526.jpg)

![](../assets/thumbs/527.jpg)

**注意：若是私有云，需要私有云的客户自行注册后创建项目获取Appid、Appsecret这两个参数**

#### <font style="color:rgb(6,6,7);background-color:rgb(255,255,255);">2、</font>配置值守后台外设参数
登录“壹家值守管理后台”，将获取到的声网参数录入系统。

+ 进入路径：【值守管理】->【外设配置】->【外设参数】。
+ 添加参数：点击【+添加】按钮，需分别添加 音频 和 视频 两个参数。
    - 业务类型：分别选择“音频”和“视频”。
    - 渠道方案：均选择 “声网”。
    - 开发参数：填入步骤1中获取的 `appId` 和 `appSecret`。

![](../assets/thumbs/528.jpg)

#### 3.设置外设配置方案
参数添加成功后，需创建一个配置方案将它们关联起来。

+ 进入路径：【值守管理】->【外设配置】->【外设设置】。
+ 新增配置：
    1. 点击【+添加】。
    2. 配置名称：自定义填写（如“云目声网配置”）。
    3. 值守机配置：选择对应的值守机型号（如“云目值守机”）。
    4. 音频方案：选择刚才添加的“声网”音频参数。
    5. 可视视频方案：选择刚才添加的“声网”视频参数。
    6. 主视频/场景视频：若无特殊需求，默认保持 “原生API”。
+ 保存：确认无误后点击【保存】。

![](../assets/thumbs/529.jpg)![](../assets/thumbs/530.jpg)

#### 4.关联通道信息
最后一步是将配置好的方案应用到具体的车场通道上。

+ 进入路径：【值守管理】->【通道信息管理】->【通道配置】。
+ 选择车场与通道：选定目标车场（如“泊特科技停车场”）及具体通道（如“入口1”）。
+ 应用方案：
    - 在“音视频方案”下拉框中，选择步骤3中创建好的配置（如 “云目声网配置”）。
+ 提交：点击【提交修改】完成配置。

![](../assets/thumbs/531.jpg)

**注意：主视频和场景视频没有特殊需求默认用原生API。**
