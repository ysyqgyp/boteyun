#### 配置服务商追缴参数
+ **入口：** 追缴管理 -> 追缴配置
+ **操作：**
    1. 点击【新增追缴配置】
    2. 新增需要配置的服务商
    3. **关键参数设置：**
        * 追缴模式： 选择“全平台”
        * 限额与笔数： 设置追缴最大限额（如30元）及最大追缴笔数（如20笔）
        * 月租车是否追缴：自定义，一般不对月租车进行追缴
        * 客服电话：  4008398982
        * 追缴类型：建议选择“自定义”，追缴时间：建议选择“半年”
        * 启用开关： 务必选择“是”
    4. 点击保存

配置追缴商户信息
+ 入口： 追缴管理 -> 配置追缴商户信息
+ 操作：点击【配置商户信息】
+ 开启开关：将“是否开启追缴”和“是否开启分润”均选择为“开启”
+ 商户号：选择默认的追缴商户号
+ 点击保存**

#### 单车场开启追缴
+ **入口：** 追缴管理 -> 配置车场
+ **操作：**在左侧“未配置车场”列表中，勾选需要开启追缴的车场（支持搜索车场ID或名称）
+ 点击移动按钮，将其移至右侧“已配置车场”列表
+ 点击【确定】完成绑定

⚠️** 注意： 系统会自动校验车场支付配置，仅支持已配置“随行付H5支付”方式的车场进行追缴**  
![](../assets/thumbs/364.jpg)

#### 关闭追缴
+ <font style="color:rgb(6, 10, 38);">根据业务需求，你可以选择以下不同粒度的关闭方式：</font>

| 关闭方式 | 适用场景 | 操作路径 | 操作方法 |
| :--- | :--- | :--- | :--- |
| 全局关闭 | 停止该服务商下所有车场的追缴业务 | 追缴管理 -> 配置车场追缴商户信息 | 将“是否开启追缴”改为关闭。 |
| 单点移除 | 仅停止某个特定车场的追缴 | 追缴管理 -> 配置车场 | 在配置界面，将该车场从“已配置”列表移回“未配置”列表。 |
| 参数关闭 | 仅针对特定车场参数调整 | 车场基本参数 -> 基础参数 | 找到“追缴模式”选项，选择不开启。 |

查看记录与退款操作
1、查询记录：

+ 入口：追缴管理 -> 追缴成功记录
+ 筛选：支持按服务商、停车场、车牌号、追缴类型等进行筛选查询

2、发起退款（原路退回）

+  在“追缴成功记录”列表中，找到需要退款的订单
+ 点击操作栏中的最后一个按钮（通常为“退款”或“操作”图标）
+ 确认退款金额及手续费信息，点击确定即可完成原路退回
