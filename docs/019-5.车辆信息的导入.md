#### 1.进入导入页面
首先，登录系统并导航至车辆管理模块。

+ 操作路径：登录系统 -> 点击【车辆管理】 -> 在列表页上方找到并点击 【导入】 按钮。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1779156476106-b53919c1-e274-401f-a9f6-a8194cbcacc3.png)

#### 2.下载导入模板
进入导入弹窗后，需要先获取系统的标准格式文件。

+ 操作动作：点击弹窗中的 【模板下载】 链接。
+ 文件说明：下载的文件名为 `车辆管理导入模版.xls`，是一个Excel工作表。
+ 注意事项：请严格按照模板中的表头字段填写，不要修改表头名称。

![](https://cdn.nlark.com/yuque/0/2026/png/67715233/1779156691906-0839c8ec-d236-4f0b-825e-ac3815f019f7.png)

#### 3.上传并确认导入
数据填写完毕并保存后，返回系统页面进行上传。

+ 操作动作：
    1. 点击 【点击上传】 区域，选择修改好的文件。
    2. 系统会显示当前上传数量（如“当前上传数量：47条”）。
    3. 确认无误后，点击 【确认导入】 按钮。
+ 限制提示：单次导入数据量不能超过1500条。如果数据量过大，建议分批次进行导入。
